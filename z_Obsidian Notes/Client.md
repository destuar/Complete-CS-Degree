## Definition

A **client** is a host/process that initiates communication to request a service or resource from another host/process (usually a [[Server]]).

## Examples

- A browser requesting a webpage over [[HTTP]]
- A mobile app calling a web API
- A DNS resolver requesting name-to-IP mapping

## Characteristics

- Typically starts the connection/session.
- Often runs on end-user devices.
- Can be interactive (browser) or automated (scripts, service calls).

## In Networking Models

In the [[4-Layer Internet Model]], clients mainly operate at the application layer while relying on transport and network layers underneath for delivery.
