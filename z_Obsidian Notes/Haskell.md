# Haskell

**Haskell** is a standardized, general-purpose, purely functional programming language with non-strict semantics and strong static typing.

## Key Concepts
- **Purely Functional**: No side effects (unlike Scheme which allows some).
- **Lazy Evaluation**: Expressions are not evaluated until their results are needed.
- **Pattern Matching**: Powerful syntax for destructuring data types.
- **Type Inference**: The compiler deduces types automatically.

## Comparison
- vs [[Scheme]]: Haskell is statically typed; Scheme is dynamically typed.
- vs [[C++]]: Haskell prevents entire classes of errors (null pointer, type mismatch) at compile time but requires a different way of thinking.

## Relevance
- Represents the "Avant-Garde" of functional programming in the course.
