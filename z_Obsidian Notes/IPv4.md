## Definition

**IPv4 (Internet Protocol version 4)** is a network-layer addressing and packet-delivery protocol using 32-bit addresses.

## Key Characteristics

- 32-bit address space (about 4.3 billion unique addresses).
- Dotted-decimal notation (for example `192.168.1.10`).
- Widely deployed across legacy and current Internet infrastructure.

## Operational Notes

- Uses subnetting ([[CIDR]]) to divide networks efficiently.
- Commonly coexists with private address ranges and [[NAT]] in modern networks.
- Header includes fields for routing, fragmentation, and lifetime (TTL).

## Limitation

Public IPv4 address exhaustion is a major reason for transition efforts toward [[IPv6]].
