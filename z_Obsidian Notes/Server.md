## Definition

A **server** is a host/process that listens for incoming requests and provides services, data, or computation to requesting entities (typically [[Client]]s).

## Examples

- Web server returning pages over [[HTTP]]
- Database server handling queries
- DNS server answering name resolution requests

## Characteristics

- Usually binds to well-known ports and waits for requests.
- Handles multiple clients concurrently.
- Focuses on availability, scalability, and fault tolerance.

## In Networking Models

In the [[4-Layer Internet Model]], server logic is at the application layer while transport/network layers provide end-to-end communication.
