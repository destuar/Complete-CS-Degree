# Scheme

**Scheme** is a dialect of **Lisp** and a primary language for teaching [[Functional Programming]].

## Key Characteristics
- **Minimalist**: Very small standard library and simple syntax.
- **Prefix Notation**: Operations come first: `(+ 1 2)` instead of `1 + 2`.
- **First-Class Functions**: Functions are treated like any other variable.
- **List-Centric**: The primary data structure is the Linked List.

## Core Primitives
- `car`: Returns the first element of a list.
- `cdr`: Returns the rest of the list.
- `cons`: Constructs a new list pair.
- `define`: Binds a value or function to a name.

## Relevance
- Used in CS107 to teach recursion, lambda calculus, and the functional paradigm without the syntax overhead of C++.
