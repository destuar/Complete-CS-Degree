## Definition

The **Application layer** contains protocols and logic used directly by end-user or service applications.

## Responsibilities

- Defines message formats and semantics for specific services
- Implements user-facing/network-facing service behavior
- Uses transport services (TCP/UDP/QUIC) to send and receive data

## Common Protocol Examples

- [[HTTP]] for web content and APIs
- DNS for name resolution
- SMTP/IMAP for email workflows

## Perspective

This layer is closest to software behavior users care about, while lower layers handle delivery mechanics.
