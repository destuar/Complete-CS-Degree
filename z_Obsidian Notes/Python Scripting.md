# Python (Scripting)

**Python** is a high-level, interpreted programming language often used for execution automation and scripting.

## Key Features (CS107 Context)
- **Dynamic Typing**: Variables are not bound to a specific type at compile time.
- **Interpreted**: Code is executed line-by-line (or via bytecode), contrasting with compiled C/C++.
- **Memory Management**: Automatic Garbage Collection (no manual `malloc`/`free`).

## Comparison
- vs [[C++]]: Slower execution, faster development.
- vs [[Scheme]]: More "practical" syntax, supports multiple paradigms (OOP, Functional, Imperative).

## Relevance
- Introduced as a modern, high-level alternative to systems languages for tasks like text processing (XML) and rapid prototyping.
